Legion device icons v1
======================

21 transparent PNG illustrations: 19 new device categories plus the approved computer and server.

Open index.html to browse the complete set and inspect it at several sizes or on light and dark backgrounds.
Every PNG preserves its generated alpha channel. Source images have not been resized, cropped or recoloured.
The mobile-devices asset contains a smartphone and tablet together as one node illustration.

prompts.json contains the exact generation prompts. Generated using the built-in image_gen tool.
manifest.json records descriptive filenames, labels, source files, dimensions and alpha verification.

These are illustrative device-type graphics. Port layouts and status indicators are visual design details, not product specifications. Keep actual model, OS, service-role and confidence labels in the application.

The assets have been prepared for use; this pack does not modify the Legion application.
