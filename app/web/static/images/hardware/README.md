# Hardware artwork

The six transparent device pictures use Joshua's recovered red replacements.
Their PNG bytes are preserved from the supplied files. The matching silhouette
vectors were retraced from each replacement's alpha channel and render at
70 × 70. The complete current artwork set and provenance are in
[the artwork manifest](../../../../../hackathons/output/flaghop-artwork/manifest.json).

Grey indicates hover or keyboard focus; purple indicates selection. The artwork
does not establish device identity, vulnerability severity or a physical link.
